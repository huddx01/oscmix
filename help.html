Configure your startup options below — the URL is generated automatically.

Reference & Examples

Currently supported devices:

- Fireface 802 (Use Port 2)

- Fireface UCX (Use Port 2)

- Fireface UCX II (Use Port 2)

- Fireface UFX (Use Port 3)

- Fireface UFX II (Use Port 3)

- Fireface UFX III (Use Port R or Port 4)

- Fireface UFX+ (Use Port R or Port 4)

The base URL is:

Parameter Description Example
midi Set connection type to MIDI
auto-connect Connect automatically after the page loads
midi-input MIDI input port name (URL-encoded)
midi-output MIDI output port name (URL-encoded)
theme Initial theme stylesheet

Note: Port names are matched case-insensitively. Always URL-encode values — the builder above does this for you.
